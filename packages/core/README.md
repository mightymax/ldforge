# @ldforge/core

Framework-independent SPARQL query lifecycle, HTTP executor, result types and plugin contracts for LDForge. N3 is loaded dynamically only when parsing Turtle/N-Triples graph results; ordinary SELECT/ASK execution does not load the RDF parser. ESM with TypeScript declarations.

See the repository README and `docs/plugins.md` for integration and transport examples. Licensed under MIT; see LICENSE.
