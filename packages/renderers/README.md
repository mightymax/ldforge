# @ldforge/renderers

Independent table, boolean and normalized JSON result renderer plugins for LDForge. Exports `createTableRenderer`, `createBooleanRenderer` and `createJsonRenderer`. Uses core localization helpers for English and Dutch labels and result captions. Renderers receive the active editor locale.

See the repository README and `docs/plugins.md` for examples and custom renderers. Licensed under EUPL-1.2; see LICENSE.
