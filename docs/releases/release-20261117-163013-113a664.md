## What changed

- Share queries from an inline panel: full editor links, automatically generated host-shortened links, SPARQL GET URLs, cURL POST/GET commands and a one-line query representation. Shortening is optional and provider-independent. Related: [#11](https://github.com/mightymax/ldforge/issues/11) and [#14](https://github.com/mightymax/ldforge/issues/14).
- Short-link loading, retryable errors and stale-query protection keep the full link available. Explicit automatic-execution links require host opt-in; ordinary links remain non-executing.
- Prefixes, sharing, keyboard shortcuts, settings and the plugin wizard now use consistent inline panels. Active toolbar icons highlight and toggle their panel; Escape restores focus. Format query is the first editor tool.
- Add missing prefixes and remove unused prefixes from the prefix panel with one undoable edit. Analysis preserves literals, comments and used aliases; syntax errors prevent unsafe removal.
- Clipboard-only copy buttons confirm success with a temporary checkmark and animation; screen readers receive a live announcement. Buttons share a consistent hover treatment and respect the theme and reduced-motion preferences.
- The demo lets Cards grow to their content height, links all package names to npm, and adds project-wide release notes backed by Markdown in the repository.
- The standalone Yasgui bundle includes the updated editor. Other packages keep their existing versions.

## Upgrade guide

Existing editor APIs remain available. **Toolbar behavior changes:** the share icon now opens a panel instead of immediately copying; plugin wizard and shortcut help open inline instead of in modal dialogs. If a host action must copy immediately, keep using `await editor.copyShareLink()` (it still persists share metadata after successful copying). Opening or copying inside the new panel does not edit or execute the query.

Optional host configuration:

```ts
const editor = createEditor(container, {
  executor,
  shortenShareUrl: async (fullUrl, query) => {
    const response = await fetch('/links', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ url: fullUrl }),
      signal: AbortSignal.timeout(10_000),
    });
    if (!response.ok) throw new Error('Shortening unavailable');
    return (await response.json()).url;
  },
  // Enable only when your recipient host honors execute=true.
  shareAutoRun: true,
});
```

`getShareLink()` remains synchronous and always returns the complete, unshortened URL. Ordinary links strip the reserved `execute` parameter. The explicit execution variant passes `execute=true` to the shortener; the receiving host must read the shared query and run it only when that parameter is set. See the [integration guide](https://ldforge.nl/guide.html#share-shortening) for the input/output contract, failure behavior and the standalone Prisma/SQLite service example.

The Cards height override applies only to the demo's host CSS; the published Cards API and defaults are unchanged.
