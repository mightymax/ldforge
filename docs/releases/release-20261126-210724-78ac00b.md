## What changed

- Add optional resultsContainer and setResultsContainer() to the editor. Move renderer selection, status, loading, errors, documentation and downloads together while preserving live results and instance isolation.
- The demo adds an icon button group beside the editor tools to switch between classic and query-left/results-right layouts. The active layout is indicated accessibly. These demo-only controls are hidden on screens up to 800px; narrow layouts stack the query and results.

## Upgrade guide

Existing integrations keep their classic layout. To separate results, provide a same-document host outside the editor. The complete panel moves together, including renderer selection, status, loading, errors, documentation and downloads. Moving it preserves live results and pending execution.

```ts
const editor = createEditor(queryHost, {
  executor,
  renderers,
  resultsContainer: resultsHost,
});

editor.setResultsContainer(otherResultsHost); // Move the live panel.
editor.setResultsContainer(); // Restore the classic layout.
editor.destroy(); // Clean up owned DOM in both hosts.
```

Load the existing editor stylesheet and place shared CSS overrides on a common ancestor or both hosts. Language and themeMainColor changes apply to both sections. Destroy the editor before unmounting either host. The standalone Yasgui bundle includes the updated editor; unrelated packages retain their versions.
