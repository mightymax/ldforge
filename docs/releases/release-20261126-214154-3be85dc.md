## What changed

- On screens up to 540 px wide, the editor tools collapse into a hamburger menu with localized action labels and touch-friendly buttons.
- The menu closes after choosing an action, pressing Escape or clicking outside. Larger screens retain the inline toolbar.
- The standalone Yasgui bundle includes the updated editor. Unrelated packages retain their versions.

## Upgrade guide

No configuration changes are required. The responsive toolbar applies automatically when using the editor stylesheet.
