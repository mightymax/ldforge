## What changed

- Style table search and filter inputs inside the embedded editor without relying on demo form styles.
- Add an accessible drag handle to resize the query editor, with keyboard controls and an option to hide it. Resizing switches to a fixed viewport and uses the existing row-count and auto-grow callbacks.
- Complete variable names from the entire query, including variables used later in WHERE, while respecting subquery projections.
