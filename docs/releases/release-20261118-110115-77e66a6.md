## What changed

- A subtle info icon on the right of the editor footer opens project links with matching icons: documentation, GitHub, release notes and the MIT license. A miniature LDForge logo and title link to the project website, with an aligned copyright row at the bottom. The panel supports keyboard access, Escape and outside-click dismissal.

## Upgrade guide

The icon is enabled by default. Set `controls: { about: false }` to hide it; the icon remains available when query tabs are hidden.
