## What changed

- Show tables at full height by default instead of inside a capped result panel. Add scroll: true and per-query table-scroll/table-height configuration, with Plugin wizard controls, to opt into a bounded viewport and large-result virtualization. Restore shared result-panel sizing when leaving the table. Update the renderer guide and packaged editor API documentation with defaults, validation, accessibility and performance considerations.
- Add renderPopup for trusted host popup DOM in Leaflet and MapLibre maps. Hosts can provide lists and action buttons, or return undefined to retain the safe default popup.
- Add an icon-only keyboard-shortcut overview in the right toolbar. The localized modal automatically shows Mac or Windows/Linux combinations, supports Escape and focus return, and can be hidden with controls.keyboardHelp. Document the new control and toolbar order.
- Show the active platform's query-execution shortcut in Run tooltips (Command on Mac/iOS, Control on Windows/Linux), matching existing CodeMirror Mod bindings. Document keyboard shortcuts, focus scope, operating-system conflicts and host keymap extensions.

## Upgrade guide

Tables now expand to display all rows by default. To retain a bounded scroll viewport and large-result virtualization, configure `createTableRenderer({ scroll: true, viewportHeight: 480 })`, or add `# view=table; table-scroll=true; table-height=480` to the query header. The new map popup callback and keyboard-help controls are optional additions. See the [renderer guide](https://ldforge.nl/plugins.html#table) for details.
