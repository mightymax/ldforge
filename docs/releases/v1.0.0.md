## What changed

- feat(table): add RDF details with themed datatype annotations
- feat: improve result views, editor sizing and endpoint management
- fix(editor): warn when requested result view is unavailable
- Add instance-scoped editor theme color API
- Improve renderer wizard and share queries with view and endpoint metadata
- Preserve query selection when adding and removing prefixes
- Avoid accumulating whitespace when toggling prefixes
- UI improvements on table rendering.
- Add APIs to inspect and remove query prefix declarations
- docs: add standalone chart integration example
